## 项目主条目（简历正文）

**scout · 长文档 Agentic RAG 系统**　2026.05 – 至今
*Python · LangChain / LangGraph · 混合检索 · 模块化评测 · 人工介入 · 可恢复运行时*

面向技术文档、政策材料、企业年报等长文档场景的完整 Agentic RAG 系统。
覆盖异步入库、混合检索、查询改写、**流式问答**、链路可观测与 ReAct 决策层；

## Bullet Points（主版本，7 条）

**技术栈：** Python、LangChain / LangGraph、混合检索、模块化评测、人工介入（HITL）

- **长文档分块与合并**：设计三级父子分块（父 1024 / 叶 256 / 重叠 50 tokens），
  检索按同父命中自动合并回父块并按相关性排序截断至 4096 tokens，解决上下文断裂。

- **混合检索与查询改写**：稠密向量 + BM25 混合检索，RRF 融合（k=60，权重 0.3 : 0.7）；
  Top-5 平均相关性低于 0.6 时触发 Step-back / HyDE 二次检索，Hybrid 异常自动降级 Dense-only。

- **Agent 决策层**：基于 ReAct 实现检索策略动态选择（HyDE / Step-back / 直接检索），
  支持工具调用（日期解析、计算器）；四重预算（步数 / 调用数 / 重复调用 / 墙钟）防死循环。

- **自建四层评测与模块级消融**：检索 / 生成 / 安全 / 轨迹四层指标 + 16 类查询标签切片；
  每个模块可开关并做消融——**混合检索是最强杠杆（+41.9pp MRR），重排次之（+16.2pp）**，
  并如实报出负向结论（查询改写 −1.1pp、复杂度路由 +2.6pp）。

- **拒答校准**：双维充分性判定（整体覆盖率 + 焦点词覆盖率），把幻觉率与误拒率分列，
  解决 RAG 中"证据不足仍自信作答"的系统性问题；定位并修复伪双字组污染分词器等底层缺陷。

- **人工介入（HITL）**：声明式风险分级（SAFE / CONFIRM / REQUIRED）、审批时可修改参数、
  副作用按血缘与调用槽位做幂等（**断点恢复不重放副作用**）、跨进程可恢复的 checkpoint、
  审批超时默认 reject（fail-closed）。

- **上下文工程与多智能体**：证据抽取式压缩（只在真正减小时生效）+ 长运行时观测压缩，
  压缩比进指标；多智能体采用**子 Agent 上下文隔离**（上行只传压缩结论与证据片段、
  失败隔离、嵌套深度写死一层）。

## 为什么这样写（三条原则）

1. **一个项目，不是两个。** 原平台的工程能力（异步入库 / 流式 / 降级）写进 bullets，
   scout 的评测与前沿能力也写进 bullets——它们属于同一个系统的不同层面。
2. **不写"后来我又做了…"。** 面试官不需要知道你的迭代顺序，只需要看到最终形态。
3. **三个测试数字按"可信度"排序**，最扎实的放最前；最脆弱的（92%）主动附失败案例补救。
