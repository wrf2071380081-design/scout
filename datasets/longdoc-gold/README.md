# 长文档语料

`scout` 评测使用的长文档语料，共 **40 篇**人工校验文本。

## 构成

| 类别 | 数量 | 说明 |
|---|---|---|
| A 股上市公司年度报告摘要 | 20 篇 | 2025 年度报告摘要，覆盖医药、半导体、矿业、消费、能源等行业 |
| 政策 / 标准 / 指引 | 20 篇 | 产业政策、行业稳增长方案、标准体系建设指南、申报指引等 |
| **合计** | **40 篇** | |

## 来源

全部为公开渠道获取的公开文件，内容未做修改：

- **企业年报**：巨潮资讯网（cninfo.com.cn）等上市公司法定信息披露平台
- **政策文件**：国务院、工业和信息化部、国家发展改革委等部委官网
- **标准文件**：国家标准全文公开系统

> **本目录只保留校验后的 Markdown 文本，不包含原始 PDF。**
> 原因有二：一是原始 PDF 语料约 65 MB，且国家标准类 PDF 的再分发可能存在版权约束；
> 二是评测与人工比对实际使用的是纯文本，Markdown 已足够复现。
> 如需复现完整入库流程，请按上述来源自行下载对应 PDF。

## 规模

按字符级三级父子分块（2400 / 1600 / 800 字符，重叠 400 / 200 / 100）切分后，
语料共产生 **988 个叶子块**。这些数字会随分块参数变化——评测报告里会绑定
`corpus_fingerprint`，所以改了语料或分块参数后，旧报告与新报告之间不可直接比较。

## 用法

评测命令通过 `--corpus` 指向本目录：

```bash
scout eval run --dataset evals/longdoc_v1.json --corpus datasets/longdoc-gold
```

加载器会读取目录下的 `.md` / `.txt` 文件，并**跳过 README**（本文件不属于待检索文档）。

## 已知缺口

- 另有 8 篇国家标准 PDF（GB/T 46254、46737、46800、46883、46978、47025、47031、47111）
  **尚未产出对应的校验文本**，因此不在本目录内。

  因此评测集的 `source_conflict` 与 `code` 两类标签暂时无法覆盖，
  详见 [`evals/README.md`](../../evals/README.md)。
