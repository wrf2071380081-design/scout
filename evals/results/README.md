## v2 标注集（200 题）的实测

```bash
scout eval run --dataset evals/longdoc_v2_draft.json --corpus datasets/longdoc-gold \
  --out reports/v2.json --markdown evals/results/longdoc_v2_report.md
```

- Recall@5 **69.5%**（v1 的 94.7%）——生成的问题更接近真实分布，天然更难
- **误拒率 23.0%**（初期为 27.7%）——根因是自动生成的问题里混入了模板套话
  （「根据知识库回答」「量化目标或要求」），评分器被自己的 token 误伤；
  过滤模板停用词后回复该指标。见此轮排查 [`docs/FINDINGS.md`](../../docs/FINDINGS.md) 第六轮
- 作答率 **75.0%** / 拒答正确率 100% / 注入泄漏率 0%
- 200 条全跑完 ~**70 ms / 题**（离线启发式模型下），说明这套评测本身跑得起来

> v2 是**草稿**——其中一部分生成的问题关键词与原文贴合度不高，
> 是下一个迭代里该动手富（或删）的内容。保留它的价值恰恰在于：
> 有 23% 的识别失败是评测"有用"的证明，不再是"零短板的展示样例"。

## 重要提醒

- **样本量仅 19 条，上述百分比只具方向性，不构成统计结论。**
- 报告中的 `keyword_coverage` 偏低是离线实现（词法抽取拼答案）的固有短板，
  不代表检索或生成链路的真实能力上限。配置真实模型后需重新测量。
- 复现命令：

```bash
scout eval run --dataset evals/longdoc_v1.json --corpus datasets/longdoc-gold \
  --out reports/after_idf.json --markdown evals/results/after_idf.md
```
