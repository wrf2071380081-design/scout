运行产物（`reports/`）不入库——那个目录是临时输出，会被反复覆盖。

## 重要提醒

- **样本量仅 19 条，上述百分比只具方向性，不构成统计结论。**
- 报告中的 `keyword_coverage` 偏低是离线实现（词法抽取拼答案）的固有短板，
  不代表检索或生成链路的真实能力上限。配置真实模型后需重新测量。
- 复现命令：

```bash
scout eval run --dataset evals/longdoc_v1.json --corpus datasets/longdoc-gold \
  --out reports/after_idf.json --markdown evals/results/after_idf.md
```
